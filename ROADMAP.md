# Roadmap

Planned work. Each item links to its issue — comment there to help or to discuss.

- **Publish to PyPI** ([#1](https://github.com/African-River-Corridors/vessel_designer/issues/1)) so it installs with `pip install vessel_designer`.
- **Public example river on an open DEM** ([#2](https://github.com/African-River-Corridors/vessel_designer/issues/2)) — a worked case on a freely downloadable elevation model
  whose licence allows commercial reuse.
- **Calibrate against more real barges** ([#3](https://github.com/African-River-Corridors/vessel_designer/issues/3)) — more built vessels with published lightship, capacity
  and draught.
- **Turn remaining baked-in defaults into inputs** ([#4](https://github.com/African-River-Corridors/vessel_designer/issues/4)) — e.g. block coefficient 0.85, the 28 m tank-length
  cap and the stern-block size. (Fabrication rates are already data: see
  `examples/barge_cost_rates.example.yaml`.)

Want something else? Open an issue with the `roadmap` label.
