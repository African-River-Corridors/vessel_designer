# Roadmap

Planned work. Each item will link to its issue once the repository is public — comment there to
help or to discuss.

- **Publish to PyPI** so it installs with `pip install vessel_designer`.
- **Public example river on an open DEM** — a worked case on a freely downloadable elevation model
  whose licence allows commercial reuse.
- **Calibrate against more real barges** — more built vessels with published lightship, capacity
  and draught.
- **Turn remaining baked-in defaults into inputs** — e.g. block coefficient 0.85, the 28 m tank-length
  cap and the stern-block size. (Fabrication rates are already data: see
  `examples/barge_cost_rates.example.yaml`.)

Want something else? Open an issue with the `roadmap` label.
